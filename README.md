🚀 Key Features
1. Multi-Mode Architecture Canvas
Draw layout designs tailored to your technical domain:

System Design: Orchestrate ingress layers, load balancers, application servers, message queues, relational databases, caches, CDNs, and object storages.
Object-Oriented Design (OOD): Model class hierarchies, define attributes and methods, and establish interface relationships.
Agentic AI Graphs: Design multi-agent planners, tool registries, vector knowledge bases, routers, and memory loop flows.
2. Interactive AI Coach Chatbot
Active Guidance: Get step-by-step Socratic walkthroughs and feedback on your design directly inside a sliding sidebar panel.
Custom Prompting: Ask the AI Coach specific questions about your design or seek optimization critiques.
Interactive MCQ Checkpoints: Work through conceptual checkpoints with instant evaluation on requirements coverage, bottleneck analyses, and single points of failure.
Interactive Suggestion Chips: Rapidly trigger advanced feedback loops (💡 Get Hint, 📋 Review Flowchart, ⚡ Analyze Bottlenecks, 📐 Best Practices).
3. Automated Layout & Connections
Auto-Layout Engine: Instantly clean up complex diagrams with smart auto-layout optimized for layout hierarchy and routing paths.
Advanced Custom Anchors: Custom node connection handles supporting up to 8 advanced connection points for clean routing and intersection avoidance.
Auto-Blank Workspace: Click sidebar categories to start from a clean slate immediately while loading the category's first phase question.
4. Technical Editors
SQL Database Schema Editor: Write structured database tables and relations directly from the sidebar.
API Spec Editor: Define REST endpoints, gRPC pathways, and JSON schemas.
Metadata Configuration: Set component characteristics (e.g., rate limits, capacities, replication strategies, model sizes, and tools registries) per node.
🛠️ Technology Stack
Frontend Library: React (Vite)
Canvas Topology: React Flow
Styling & Design System: Tailwind CSS (Premium Dark Theme)
Icons: Lucide React
State Management: Custom lightweight reactive stores
💻 Getting Started
Prerequisites
Node.js (v18+)
npm or yarn
Installation
Clone the project.
Install the dependencies:
bash

npm install
Running Locally
To launch the developer environment locally, run:

bash

npm run dev
Then open http://localhost:5173 in your browser.

Building for Production
To bundle and optimize the application for production delivery, run:

bash

npm run build
The compiled output will be generated inside the dist/ directory.
